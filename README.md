# Dr. Maya Reynolds, PsyD - Therapy Practice Website

A professional, responsive website for Dr. Maya Reynolds, a licensed clinical psychologist specializing in anxiety, trauma, and burnout therapy in Santa Monica, California.

## 🎯 Project Overview

This website redesigns a therapy practice homepage with a new theme, copy, and branding tailored to Dr. Maya Reynolds' practice. The design features a calming sage green color palette and warm, professional imagery that reflects the therapeutic approach.

## 🎨 Design

**Color Palette:**
- Primary: Sage Green (#5b8c7d) - Healing and growth
- Secondary: Warm Cream (#e8c4a0) - Approachable and soft
- Accent: Gold (#d4a574) - Expertise and value

**Features:**
- Fully responsive design (mobile, tablet, desktop)
- Smooth scroll animations
- Hover effects on interactive elements
- Floating call-to-action button
- Lazy loading for optimal performance

## 🛠️ Tech Stack

- **Framework:** Next.js 16.3.8 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Deployment:** Vercel

## 📄 Website Sections

1. **Hero** - Main headline with call-to-action
2. **Doctor Bio** - Introduction to Dr. Maya Reynolds with photo
3. **About** - Background and approach
4. **Services** - Three main therapy services (Anxiety, Trauma, Burnout)
5. **Approach** - Therapeutic philosophy and methods
6. **Our Office** - Office location and details (custom section)
7. **FAQ** - Common questions about therapy
8. **Contact** - Contact information and booking options
